How could these channels produce 500 registrations?
This is the most important part of the marketing plan: show the arithmetic behind your target.

Use the following as a planning model, not a guarantee.
Channel	Assumption	Registration target
College clubs and student representatives	20 active partners × 12 registrations each	240
WhatsApp and class communities	10 permitted group distributions × 10 registrations each	100
Student referral loop	100 registrations attributed to referral links	100

There is a potential overlap between these channels. For example, a student might see a WhatsApp post, visit LinkedIn, and then register using a friend's referral link.

For the plan to be credible, assign each registration to one primary source using a consistent attribution rule, deduplicate by student identity, and report unknown sources separately. The targets above assume that this is done.
How I would validate the assumptions
Before claiming that this plan can reach 500 students, I would ask:
1. Can we realistically secure 20 student-community partners within two days?
2. Can each partner reach enough final-year students?
3. Are the WhatsApp groups relevant, active, and open to this kind of promotion?
4. How many referrals can reasonably come from the initial registrants?
5. Which channel produces registrations rather than just clicks?
If the first two assumptions fail, the plan needs to change. You cannot compensate for a lack of distribution simply by making the landing page more attractive.
A better way to forecast
Let:
- \(P\) = active distribution partners.
- \(R_p\) = average registrations attributed to each partner.
- \(R_w\) = registrations from WhatsApp distributions.
- \(R_r\) = registrations from referrals.
- \(R_o\) = registrations from other channels.
Then:
\[
R_{\text{total}} = P \times R_p + R_w + R_r + R_o
\]
Your goal is:
\[
R_{\text{total}} \geq 500
\]
The dashboard should compare actual registrations against these assumptions daily.

If you are behind target, it should identify the shortfall and the channels most likely to help close it.

The default should be organic distribution. Use existing design tools and student networks where possible, and release discretionary spending only after observing actual results.

If no paid promotion is necessary, preserve the budget rather than spending it just to use the allocation.
One useful metric
\[
\text{Cost per registration} =
\frac{\text{Campaign spend}}{\text{Attributed registrations}}
\]
For example, if the entire ₹2,000 budget were spent to obtain 500 registrations:
\[
\text{Cost per registration} = \frac{2000}{500} = ₹4
\]
That is a budget scenario, not a prediction that you will achieve ₹4 per registration. Report the actual figure only after real spending and registrations have occurred.
